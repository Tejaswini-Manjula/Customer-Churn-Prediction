# 📊 Customer Churn Prediction for a Telecom Company

## 📌 Overview

Customer churn is one of the biggest challenges faced by telecom companies. Predicting customers who are likely to discontinue their services helps businesses take proactive measures to improve customer retention.

This project uses Machine Learning techniques to analyze customer demographics, account information, and service usage patterns to predict customer churn.

---

## 🎯 Problem Statement

Develop a machine learning model that predicts whether a telecom customer is likely to churn based on historical customer data.

---

## 📂 Dataset

- **Dataset:** IBM Telco Customer Churn Dataset
- **Records:** ~7,000 customer records
- **Target Variable:** Churn (Yes / No)
